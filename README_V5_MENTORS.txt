Как обновить GitHub:
1) Удалить старые index.html / app.js / platform-v3.css / platform-v3.js / platform-v4.css / platform-v4.js, если GitHub спрашивает замену — выбрать Replace.
2) Загрузить все файлы из этой папки в корень репозитория.
3) Обязательно загрузить новые файлы: platform-v5.css и platform-v5.js.
4) Подождать 1–3 минуты и обновить сайт Ctrl+F5.
